# Khinsider Extension per Echo/Echo Nightly

Estensione per [Echo](https://github.com/brahmkshatriya/echo)/[Nightly](https://github.com/itsmechinmoy/echo-nightly) che permette di cercare e ascoltare
colonne sonore di videogiochi dal sito khinsider (mirror khinsider.squid.wtf). Codice creato "a sentimento" tramite l'ausilio di Deepseek V4 Flash.

## Panoramica
- **Home** con varie sezioni per navigare il sito e scoprire nuova musica.
- **Ricerca**: cerca album per titolo
- **Libreria**: attraverso la funzionalità di login, visiona gli ultimi album ascoltati, gli album preferiti e le tue playlist personali.

## Funzionalità
- **Album**: apri un album e riproduci le tracce in formato MP3 o FLAC
- **Download**: scarica in locale singole tracce o anche interi album con un solo click
- **Sincronizzazione**: crea playlist e salva gli album preferiti direttamente dall'app: il tuo account verrà immediatamente aggiornato, anche quando lo visualizzerai dal sito

## Installazione
1. Apri la pagina [Releases](https://github.com/zippatias/echo-khinsider-extension/releases)
2. Scarica il file `.eapk` più recente
3. Installalo sul telefono (consenti l'installazione da fonti sconosciute)
4. Apri Echo: l'estensione "Khinsider" apparirà nell'elenco delle estensioni

---　English

# Khinsider Extension for Echo/Echo Nightly

Extension for [Echo](https://github.com/brahmkshatriya/echo)/[Nightly](https://github.com/itsmechinmoy/echo-nightly) that lets you search for and listen to
video game soundtracks from the khinsider website (khinsider.squid.wtf mirror). Vibecoded with the help of Deepseek V4 Flash.

## Overview
- **Home** with various sections to browse the site and discover new music.
- **Search**: search for albums by title
- **Library**: through the login feature, view your history, favorite albums, and personal playlists.

## Features
- **Album**: open an album and play tracks in MP3 or FLAC format
- **Download**: download individual tracks or entire albums, locally, with a single click
- **Sync**: create playlists and save favorite albums directly from the app: your account will be updated instantly, even when viewed from the website

## Installation
1. Open the [Releases](https://github.com/zippatias/echo-khinsider-extension/releases) page
2. Download the latest `.eapk` file
3. Install it on your phone (allow installation from unknown sources)
4. Open Echo: the "Khinsider" extension will appear in the extensions list

# Khinsider 拡張機能（Echo / Echo Nightly 用）

[Echo](https://github.com/brahmkshatriya/echo)/[Nightly](https://github.com/itsmechinmoy/echo-nightly)向けの拡張機能で、khinsiderのウェブサイト（khinsider.squid.wtf ミラー）から
ゲームのサウンドトラックを検索・再生できます。コードは Deepseek V4 Flash の助けを借りて雰囲気コードされました。

## 概要
- **ホーム**：サイトを閲覧し、新しい音楽を発見するための各種セクション。
- **検索**：タイトルでアルバムを検索
- **ライブラリ**：ログイン機能により、最近聴いたアルバム、お気に入りのアルバム、自分のプレイリストを表示。

## 機能
- **アルバム**：アルバムを開き、MP3またはFLAC形式でトラックを再生
- **ダウンロード**：個別のトラックやアルバム全体をワンクリックでローカルに保存
- **同期**：アプリから直接プレイリストを作成し、お気に入りのアルバムを保存：アカウントは即座に更新され、ウェブサイトで確認しても反映されています

## インストール方法
1. [Releases](https://github.com/zippatias/echo-khinsider-extension/releases) ページを開く
2. 最新の `.eapk` ファイルをダウンロードする
3. スマートフォンにインストールする（不明なソースからのインストールを許可してください）
4. Echoを開くと、拡張機能リストに「Khinsider」が表示されます

# Khinsider 擴充功能（適用於 Echo / Echo Nightly）

[Echo](https://github.com/brahmkshatriya/echo)/[Nightly](https://github.com/itsmechinmoy/echo-nightly) 的擴充功能，讓你能夠搜尋並收聽
khinsider 網站（khinsider.squid.wtf 鏡像站）上的電玩遊戲原聲帶。透過 Deepseek V4 Flash 的協助進行氛圍編程。

## 概覽
- **首頁**：提供多個區塊，方便瀏覽網站並發掘新音樂。
- **搜尋**：依標題搜尋專輯
- **資料庫**：透過登入功能，查看最近收聽的專輯、收藏的專輯以及個人播放清單。

## 功能
- **專輯**：開啟專輯並以 MP3 或 FLAC 格式播放曲目
- **下載**：只需點擊一下，即可將單曲或整張專輯下載至裝置本機
- **同步**：直接在應用程式中建立播放清單並收藏喜愛的專輯：你的帳戶會立即更新，即使在網站上查看也會同步顯示

## 安裝方式
1. 開啟 [Releases](https://github.com/zippatias/echo-khinsider-extension/releases) 頁面
2. 下載最新的 `.eapk` 檔案
3. 安裝到手機上（請允許安裝來自不明來源的應用程式）
4. 開啟 Echo：擴充功能列表中將會出現「Khinsider」
